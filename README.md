# ValStretch

简体中文 | [English](README_EN.md)

🎮 VALORANT 真实拉伸分辨率工具。

本工具用于在游戏启动和退出时自动应用 / 恢复拉伸相关设置，减少手动切换分辨率和反复调整配置的麻烦。

> ⚠️ 本软件完全免费，谨防假冒套壳收费版本。

## ✨ 主要功能

- ⚡ 一键应用 / 恢复真实拉伸分辨率。
- 🔁 默认的「禁用监视器」方式支持自动拉伸：在自动页显式绑定国服 / 国际服，按本地游戏 PID 运行，游戏退出后恢复 Monitor 和原始桌面模式。
- 🖥️ 支持 NVIDIA / AMD 驱动模式管理、常用 4:3 预设和自定义分辨率。
- 🛠️ 开启自动拉伸时自动检查并修正已检测到的游戏配置，无需单独点击修复按钮；也可以在自动页关闭「允许修改 cfg」，只管理显示器和分辨率。
- ⌨️ 手动界面可为每个已添加的分辨率设置全局快捷键。
- 🖱️ 支持 16:9 到 4:3，以及 CS2 与 VALORANT 之间的双向鼠标灵敏度换算。
- 🔔 支持屏幕通知、托盘运行、开机自启动和最小化到托盘。
- 📂 支持国服 / 国际服配置路径分别保存。
- 🚀 提供可检测、可调整的 Windows 性能优化页：游戏模式、控制器启动 Game Bar、后台录制和高性能电源计划。
- 🌍 界面支持简体中文、繁体中文（台湾 / 香港）、英语、日语、韩语、俄语。

## 📥 下载与运行

1. 前往 [Releases](https://github.com/ZyphrZero/ValStretch/releases) 下载最新版 `valstretch-<version>-windows-x64.zip`。
2. 解压后运行其中的 `valstretch.exe`。
3. 首次启动请先阅读并确认「使用须知」。
4. 按照界面提示选择 VALORANT 安装或配置目录，也可以使用「自动检测」。

每个发布包都附带 `SHA256SUMS.txt`。如需校验文件完整性，可在 PowerShell 中执行：

```powershell
Get-FileHash .\valstretch.exe -Algorithm SHA256
```

## 📖 使用步骤

### 🎯 推荐：禁用监视器方式（默认）

1. 在「高级设置」中保留默认的「禁用监视器方式」，按需点击「自动检测」或填写国服 / 国际服的安装或配置目录；然后在自动页的「自动区服」中选择本次绑定的区服。目录用于协助定位和修正配置，不是自动模式的硬性前置条件。
2. 在「预创建分辨率」中添加目标模式。建议使用 `1440x1080` 或 `1920x1440`；如果驱动中已有完全相同的模式，工具会直接登记并复用。
3. 在「可应用分辨率」列表中点击「设为目标」。`1280x882` 是自动流程使用的引导分辨率，不能设为最终目标。
4. 按需要设置「引导分辨率延迟时间」。建议 `3000-5000ms`，给游戏窗口留出完成引导切换的时间。
5. 开启「自动拉伸」。工具会尽力修正已检测到的绑定区服配置；游戏启动后按已绑定区服和本地 PID 完成引导与目标分辨率切换，游戏退出后恢复 Monitor 与原始桌面模式。

🖥️ 游戏内「视频」设置中的全屏模式请选择「全屏窗口（无边框）」，纵横比选择「填充」，其他组合可能无法生效。

🔎 多显示器用户注意：自动拉伸期间会临时停用全部显示器，请确保 VALORANT 显示在 Windows 主显示器上，否则切换会超时并自动恢复。

🛠️ 如不想让工具读写游戏配置，可关闭自动页的「允许修改 cfg」：自动路线仍会管理 Monitor 和显示模式，但不会读取或写入 `GameUserSettings.ini`。

如果配置文件为只读、配置目录缺失或进程路径不可查询，自动拉伸会显示带具体路径和原因的警告，但不会因此停止；Monitor 和桌面模式仍按绑定区服继续执行。关闭游戏，在文件属性中取消「只读」或补充对应目录后，可重新开启自动拉伸再次尝试修正配置。

如果提示缺少 `[/Script/ShooterGame.ShooterGameUserSettings]` 配置节，请不要手工添加该节。完全退出 VALORANT 和 Riot Client，把提示路径中的 `GameUserSettings.ini` 重命名为 `GameUserSettings.ini.broken` 作为备份；然后启动一次对应区服 VALORANT，进入主界面并保存任意一项游戏设置，再正常退出游戏。等待游戏重新生成完整配置后，重新开启自动拉伸。

### 🖱️ 手动使用

切换到手动界面后，可以单独「禁用监视器 / 开启监视器」、应用已添加的分辨率，并显式「恢复原始分辨率」。若监视器仍处于手动禁用状态就切回自动界面并开启自动拉伸，工具会先尝试恢复这次手动事务；恢复失败时，请返回手动界面点击「开启监视器」，确认恢复成功后再重试。

高级设置中仍保留旧 cfg 配置文件路线，但当前默认和推荐流程是「禁用监视器方式」。两条路线的事务和恢复逻辑彼此独立。

主窗口使用兼容 Windows 10 和 Windows 11 的应用内无边框标题栏：顶部空白区可拖动窗口，窗口边缘可拖拽调整大小，窗口尺寸会被记住；标题栏提供最小化和关闭按钮，关闭按钮遵循「关闭面板时最小化到托盘」设置。

### ⚡ 性能优化

点击标题栏中的性能图标可以查看四项 Windows 当前状态。拨动任一开关会在后台立即同步对应 Windows 设置并回读确认；工具只修改当前 Windows 用户的游戏模式、控制器启动 Game Bar、Game DVR / 后台捕获设置，以及当前电源计划；不会卸载 Game Bar、停止系统服务或注入游戏进程。其中开启「关闭控制器启动 Game Bar」，会禁用 Windows「允许控制器打开 Game Bar」入口，但不会屏蔽 `Win+G`。

开关表示对应 Windows 功能的目标状态，拨动后会立即写入并回读验证；不会保存或恢复原始设置。如果部分写入或复检失败，已经成功写入的项目不会自动恢复，请按页面中的具体原因处理后点击刷新，再次拨动对应开关重试。关闭高性能计划开关会同步到 Windows 内置「平衡」计划。工具不会把原本就符合目标的设置强行反向修改，因此右侧 Windows 实际状态仍可能显示游戏模式开启、控制器入口关闭、录制关闭或高性能计划启用。

### ⌨️ 「禁用监视器」路线快捷键

在「可应用分辨率」列表中点击分辨率右侧的键盘图标，直接按下快捷键并保存。支持单独使用 `A-Z`、`0-9`、`F1-F24` 和常用标点键，也可组合 `Ctrl`、`Alt`、`Shift`、`Win`；字母按当前键盘布局的逻辑字母录入，数字、功能键和标点按物理键位录入，与 Windows 全局快捷键一致。无修饰键的单键会成为系统全局快捷键，可能影响其他程序接收该按键。

全局快捷键仅在 ValStretch 运行、当前选择「禁用监视器方式」且停留在手动界面时生效；切到自动界面会注销这些快捷键。窗口最小化、隐藏到托盘或 VALORANT 位于前台时仍可触发。快捷键只切换主显示器的分辨率、色深和刷新率，并保留「恢复原始分辨率」所需的状态；不会改写 VALORANT 配置文件，也不会调整 NVIDIA 缩放设置。

## ❓ 常见问题

### 🖼️ 仍然有黑边怎么办？

先确认目标分辨率是显示器和显卡支持的分辨率，例如 `1440x1080`、`1280x960`、`1920x1440`。

如果仍然有黑边，请在 ValStretch「高级设置」中开启「NVIDIA 缩放模式覆盖」。该开关直接读写 NVIDIA 驱动设置，与 NVIDIA 控制面板 / NVIDIA App 同步，游戏或 ValStretch 退出时会保持当前状态。

开启覆盖后如果仍有黑边，再检查 NVIDIA 控制面板或 NVIDIA App 中的缩放方式是否为「全屏 / Full」，以及显示器 OSD 缩放设置。

### 🤔 自动模式没反应怎么办？

确认这几件事：

- 自动页的「自动区服」已选择要绑定的区服。目录检测用于配置协作；即使目录暂时未找到，Monitor 自动模式也不会仅因配置缺失而停止。
- 已创建目标分辨率并点击「设为目标」；`1280x882` 不能作为目标。
- 游戏进程和游戏窗口已经真正启动，且工具没有被安全软件拦截。
- 多显示器环境下，VALORANT 显示在 Windows 主显示器上。
- 配置文件没有「只读」属性，错误通知和日志中会显示具体失败路径。
- 手动界面没有尚未恢复的监视器或原始分辨率事务。

如果某个游戏 PID 已经应用失败，为避免反复切换和闪屏，本次游戏运行期间不会再次尝试。请按错误提示处理后完全退出 VALORANT，再重新启动游戏。

### 🔒 为什么提示配置文件只读？

Windows 的「只读」属性会阻止工具原子写入配置。根据警告中的完整路径找到 `GameUserSettings.ini`，关闭游戏，打开文件属性并取消「只读」，然后重新开启自动拉伸再次尝试。修正失败本身不会阻止 Monitor 自动流程，工具也不会把写入失败伪装成目录检测成功。

### ↩️ 关闭工具前需要手动恢复吗？

自动模式会在游戏退出、关闭自动拉伸或退出 ValStretch 时尝试恢复本周期禁用的 Monitor 和完整原始桌面模式。

手动模式不同：退出程序会尝试重新启用本次禁用的监视器，但不会自动清除手动桌面分辨率快照。结束使用前应点击「恢复原始分辨率」；如果监视器仍被禁用，也应先点击「开启监视器」。
